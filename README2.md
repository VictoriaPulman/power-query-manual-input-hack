# Универсальная инструкция по импорту данных из PDF в Excel 2019

Скрипт для Расширенного редактора Power Query, который автоматически определяет количество столбцов в PDF и динамически разворачивает их все (хоть 3, хоть 10, хоть 50 колонок).

## 🛠️ Чек-лист пошагового подключения

### Шаг 1. Создание базового запроса
- [ ] Создать в любой папке на компьютере пустой текстовый файл (например, `test.txt`).
- [ ] Открыть книгу Excel 2019.
- [ ] Перейти на вкладку **Данные** → **Получить данные** → **Из файла** → **Из текстового/CSV-файла**.
- [ ] Выбрать созданный файл `test.txt` и нажать **Импорт**.
- [ ] В окне предварительного просмотра нажать **Преобразовать данные** (или *Изменить*), чтобы открыть редактор Power Query.

### Шаг 2. Переход в Расширенный редактор M
- [ ] На вкладке **Главная** найти блок *Запрос* (в левой части ленты) и нажать кнопку **Расширенный редактор**.
- [ ] Полностью удалить весь автоматически сгенерированный код, который находится в открывшемся окне.

### Шаг 3. Применение универсального кода на языке M
- [ ] Скопировать готовый универсальный код, представленный ниже, и вставить его в окно Расширенного редактора.
- [ ] Заменить демонстрационную строку `"C:\Путь_К_Вашей_Папке\Имя_Файла.pdf"` на реальный путь к вашему PDF-документу.
- [ ] Нажать кнопку **Готово** в правом нижнем углу.

```powerquery
let
    // 1. Подключаемся к файлу (ЗАМЕНИТЕ ПУТЬ НА СВОЙ)
    Источник = Pdf.Tables(File.Contents("C:\Путь_К_Вашей_Папке\Имя_Файла.pdf")),
    
    // 2. Отбираем только таблицы, чтобы корректно собрать имена столбцов
    ТолькоТаблицы = Table.SelectRows(Источник, each ([Kind] = "Table")),
    
    // 3. Автоматически вычисляем список абсолютно всех уникальных колонок в документе
    СписокКолонок = List.Distinct(List.Combine(List.Transform(ТолькоТаблицы[Data], Table.ColumnNames))),
    
    // 4. Динамически разворачиваем все найденные колонки
    #"Развернутый элемент Data" = Table.ExpandTableColumn(ТолькоТаблицы, "Data", СписокКолонок)
in
    #"Развернутый элемент Data"
```

### Шаг 4. Выгрузка данных в Excel
- [ ] Убедиться, что в окне предпросмотра отображаются корректные, склеенные из всех страниц данные со всеми существующими столбцами.
- [ ] Нажать кнопку **Закрыть и загрузить** (крайняя левая кнопка на вкладке «Главная»).
- [ ] Проверить, что Power Query закрылся, а данные импортировались на лист Excel в виде единой динамической умной таблицы.
