# 🛠️ Power Query Manual Input Workaround / Обходной путь для ручного ввода данных

Если в вашей версии Excel / Power Query **пропала кнопка «Ввести данные» («Создать таблицу»)** и интерфейс выглядит пустым, не паникуйте. Само окно ручного ввода никуда не исчезло из движка программы — разработчики просто убрали его из графического меню. 

Ниже представлен универсальный лайфхак, как вернуть привычный конструктор таблиц с помощью короткого кода за 15 секунд.

> **Проблема:** В интерфейсе отсутствует стандартная кнопка для создания таблицы вручную.
> **Решение:** Восстановить стандартное окно редактирования через пустой запрос и Расширенный редактор.

---

### Инструкция: Создание таблицы для ручного ввода в Power Query

1. **Создать пустой запрос**
   * Нажать **«Создать источник»** (справа вверху во вкладке Главная) -> навести на **«Другие источники»** -> выбрать **«Пустой запрос»**.

2. **Открыть редактор кода**
   * В блоке слева **«Запросы»** нажать на наш новый источник правой кнопкой и выбрать **«Расширенный редактор»**.

3. **Вставить код**
   * Стереть всё в открывшемся окне, вставить этот код и нажать **«Готово»**:
     ```powerquery
     let
         Источник = Table.FromRows(Json.Document(Binary.Decompress(Binary.FromText("i44FAA==", BinaryEncoding.Base64), Compression.Deflate)), let _t = ((type nullable text) meta [Serialized.Text = true]) in type table [Столбец1 = _t])
     in
         Источник
     ```

4. **Заполнить данные**
   * Справа в панели «Параметры запроса» в списке **«Примененные шаги»** нажать на **шестеренку ⚙️** рядом со словом *«Источник»*. 
   * В открывшемся окне заполнить любые значения, строки и столбцы вручную.
